{% extends 'partials/base.html' %} {% comment %} The permission-denied page. Django's `HttpResponseForbidden("some text")` renders exactly that string and nothing else: black serif on white, no logo, no navigation, no way back. To a nurse who has tapped a link in her own sidebar that reads as a crashed server, not as "this screen is not for you" — and a browser QA pass counted twenty visible links that dumped staff onto it. So `accounts.decorators.denied()` renders this instead: inside the app shell, in the hospital's own branding, with a plain sentence and a Back button. It is still HTTP 403 — only the presentation changes. `reason` is the one-line explanation the decorator passes. It has to be readable by the person in front of it, so it never names a feature key. {% endcomment %} {% block title %}Not available to you{% endblock %} {% block page_title %}Access{% endblock %} {% block content %}
