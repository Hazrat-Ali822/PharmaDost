What to type into the machine

In the machine's menu look for Comm → Cloud Server, or ADMS, or Network → Server — the wording differs by model. Enter:

Server address {{ server.host }}
Port {{ server.port }}
ModeHTTP / ADMS / Push — whichever it calls it
Real-time uploadOn

Leave any "path" or "URL" box at its default. The machine adds /iclock/ itself and that is what this server is listening on. Nothing else needs setting up — once the machine can reach this address it sends every punch on its own.
