How this works, start to finish

1

Register the machine hereIN SEHATYAR

Once, per machine. You need its serial number — the form is at the bottom of this page.

2

Type this server's address into the machineON THE MACHINE

Once, per machine. The exact values are in the next box. After this the machine sends everything by itself — you never export or upload a file.

3

Add each employee to SehatyarIN SEHATYAR

Once, per person — Add employee: name, designation, salary. They do not need a login or an email address. A guard or a cleaner is on the payroll and never touches a screen.

4

Enrol their thumb, and note the number it gives themON THE MACHINE

On the machine: Menu → User Management → New User. It assigns a User ID — 1, 2, 3 and so on — then scans the finger. Write that number down next to the name.

5

Put that number against the personIN SEHATYAR

Map staff. This is the only link between the two — the machine knows numbers, Sehatyar knows people. Do it whenever suits: scans recorded before the mapping existed are kept, and they count the moment you add it.

6

That is all — from here it runs itself

A "scan" is one touch of the reader. Coming in is one, going home is another — so a normal day is two scans per person, and Sehatyar works the day out from the first and the last. Each one arrives within seconds. At month end open Build attendance to turn them into present / half / absent days, check what it proposes, and the payslip picks up the deduction.
